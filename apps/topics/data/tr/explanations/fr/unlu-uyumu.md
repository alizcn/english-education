L'harmonie vocalique est l'une des règles les plus importantes de la grammaire turque. Elle signifie que les voyelles dans les suffixes doivent s'adapter à la voyelle finale du mot racine. C'est une règle constante qui s'applique à presque tous les suffixes du turc, ce qui en fait une caractéristique fondamentale à maîtriser dès le début de l'apprentissage.

## Les deux groupes de voyelles

Toutes les voyelles turques appartiennent à l'un de ces deux groupes selon leur position articulatoire :

- Voyelles postérieures : a, ı, o, u
- Voyelles antérieures : e, i, ö, ü

C'est la dernière voyelle du mot qui détermine auquel de ces deux groupes le mot appartient. Aucune autre voyelle n'a d'importance pour cette règle.

## Le principe fondamental

La règle est simple et logique : si la dernière voyelle du mot racine est postérieure, les voyelles des suffixes doivent aussi être postérieures. Si la dernière voyelle du mot racine est antérieure, les voyelles des suffixes doivent aussi être antérieures.

Voici des exemples avec le suffixe du pluriel -ler ou -lar :

ev + ler = evler (la maison + pluriel : les maisons)
kap + lar = kaplar (le pot + pluriel : les pots)
köpek + ler = köpekler (le chien + pluriel : les chiens)
kız + lar = kızlar (la fille + pluriel : les filles)

## L'harmonie avec les suffixes possessifs

Le suffixe possessif de la première personne du singulier (-im, -ım, -üm, -um) illustre parfaitement le fonctionnement de l'harmonie vocalique. Chaque suffixe change en fonction de la dernière voyelle du mot :

ev + im = evim (ma maison - e antérieur → i antérieur)
kap + ım = kapım (mon pot - a postérieur → ı postérieur)
kız + ım = kızım (ma fille - ı postérieur → ı postérieur)
gül + üm = gülüm (ma rose - ü antérieur → üm antérieur)

## L'harmonie s'applique à tous les suffixes

L'harmonie vocalique ne s'applique pas seulement à quelques suffixes particuliers. Elle affecte presque tous les suffixes du turc : les suffixes de pluriel, possessifs, de cas (locatif, accusatif, etc.), verbaux et autres. Comprendre ce mécanisme est donc essentiel pour former correctement n'importe quel mot turc.

Le locatif montre bien cette application universelle :

ev + de = evde (dans la maison)
kap + ta = kapta (dans le pot)
kız + da = kızda (chez la fille)
gül + de = gülde (dans la rose)

## Les erreurs les plus courantes

Les apprenants francophones commettent régulièrement ces erreurs :

- Ignorer complètement l'harmonie et utiliser la même forme de suffixe pour tous les mots : *kapim au lieu de kapım
- Penser que seule la première voyelle du mot importe, au lieu de la dernière : *evlar au lieu de evler
- Confondre les deux groupes de voyelles ou oublier leurs compositions exactes
- Appliquer l'harmonie seulement aux suffixes singuliers et l'oublier pour les pluriels ou les verbes
- Mélanger l'harmonie vocalique avec d'autres règles comme l'assouplissement des consonnes

## Pratique avec différents suffixes

Pour bien maîtriser la règle, observez comment un seul mot reçoit différents suffixes en respectant l'harmonie :

Avec ev (e antérieur) :
evler (pluriel), evim (mon), evde (locatif), evi (accusatif)

Avec kap (a postérieur) :
kaplar (pluriel), kapım (mon), kapta (locatif), kapı (accusatif)

Avec kız (ı postérieur) :
kızlar (pluriel), kızım (mon), kızda (locatif), kızı (accusatif)

Avec gül (ü antérieur) :
güller (pluriel), gülüm (mon), gülde (locatif), gülü (accusatif)
