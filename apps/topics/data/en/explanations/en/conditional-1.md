The First Conditional is used to talk about real or possible situations in the future and their probable results. It expresses the idea that if one thing happens, another thing will happen as a consequence. This structure is the most common way to discuss future possibilities and is used for situations that are likely to happen.

## When to Use the First Conditional

- Use the First Conditional when you are talking about a real possibility in the future. The condition is something that may or will probably happen.
- It suggests that the outcome is likely or certain if the condition is met.
- You use it for giving instructions, making promises, threats, or warnings.
- Common in decisions, advice, and statements about cause and effect: If you study hard, you will pass the exam. If it rains tomorrow, the picnic will be cancelled. If you heat water to 100 degrees, it will boil.

## Structure and Formation

- The First Conditional follows the pattern: If + present tense + will + base verb
- The if clause uses a present tense verb. This is usually the simple present: If you arrive late, I will be angry. If she calls, we will know the answer.
- The main clause uses will or another modal (can, may, might) with the base form of the verb.
- The two clauses can appear in either order. If you come to the party, you will have fun. OR You will have fun if you come to the party.
- Both word orders are grammatically correct, but the if clause at the beginning is more common in formal writing.

## Positive Sentences

- The if clause uses a present tense form of the verb. If I win the lottery, I will buy a house. If he finishes his homework, he can watch television.
- The main clause starts with the subject and uses will or a modal: Sarah will be happy if you give her the gift. Children can swim if they take lessons.
- Both clauses must follow the same time reference (future).
- Common verbs in positive statements: If you practice every day, you will improve. If she arrives early, she will help us prepare. If they save money, they can afford a vacation.

## Negative Sentences

- To make the if clause negative, put not after the present tense auxiliary or use no with a noun: If you do not study, you will fail. If you don't call him, he will be disappointed. If there is no rain, the plants will die.
- To make the main clause negative, put will not (won't) before the base verb: If you eat too much sugar, you will not feel well. If they don't arrive on time, we won't wait for them.
- Both parts can be negative: If you don't practice, you won't get better. If it doesn't rain, the game will not be cancelled.
- It is also possible to use other modals in negative form: If you don't sleep, you may not be able to concentrate.

## Questions

- To form a yes-no question, put will before the subject of the main clause: Will you be happy if I come? Will they finish on time if we help? Will she understand if you explain it slowly?
- The if clause remains in positive form with present tense: Will you pass if you study? Will we arrive on time if we leave now?
- To make questions about the if clause, use the interrogative form in that clause: What will happen if you don't go? Where will you go if the weather is bad? What will you do if you lose your job?
- Wh-questions that focus on the main clause: If it rains, what will you do? If you win, how will you celebrate?

## Time Expressions and Markers

- Time expressions help show the future timing: tomorrow, next week, in two hours, later, tonight, soon.
- These appear in either the if clause or main clause: If you see him tomorrow, tell him the news. If it's sunny next weekend, we will go hiking.
- Words like always, never, immediately show frequency or speed: If you always eat vegetables, you will stay healthy. If you ever have a problem, let me know.
- Conditional markers include if, unless, and as long as: Unless you call, I will not know. As long as you finish by Friday, you will be fine.
- Unless means if not and reverses the logic: Unless you study, you will fail = If you do not study, you will fail.

## Common Learner Mistakes

- Using will in the if clause: WRONG: If you will study, you will pass. CORRECT: If you study, you will pass.
- Forgetting will in the main clause: WRONG: If it rains, the game is cancelled. CORRECT: If it rains, the game will be cancelled.
- Confusing unless with if: Unless is if not, so do not use both together. WRONG: Unless you don't study, you will fail. CORRECT: Unless you study, you will fail.
- Using the wrong tense in the if clause: WRONG: If you studied, you will pass (this mixes past and future). CORRECT: If you study, you will pass.
- Putting the if clause with only a noun instead of a verb: WRONG: If rain tomorrow. CORRECT: If it rains tomorrow, the game will be cancelled.
- Using may or might in the if clause instead of simple present: WRONG: If you may call me, I will help. CORRECT: If you call me, I will help.
- Not understanding the difference between the First and Second Conditional. The First Conditional is about real possibilities (If you study, you will pass). The Second Conditional is about imaginary situations (If you studied, you would pass) — but that is a different topic.
