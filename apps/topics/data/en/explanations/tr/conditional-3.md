Third Conditional, geçmişte gerçekleşmeyen durumlar hakkında hayal etmek, pişman olmak veya alternatif sonuçları tartışmak için kullanılan bir yapıdır. Bu yapı, eğer şeyler farklı olsaydı ne olurdu sorusunu sorar ve hipotetik sonuçları ifade eder.

## Kullanım Alanları

- Geçmişte gerçekleşmeyen durumlar hakkında düşünmek için: If I had studied harder, I would have passed the exam.
- Pişmanlık veya üzüntü ifade etmek: If you had told me the truth, I wouldn't have been angry.
- Alternatif geçmiş senaryoları: If she had moved to London, she would have found a better job.
- Başkasının geçmiş kararlarının sonuçlarını tartışmak: If he had invested in that company, he would have become rich.

## Olumlu Yapı

- Yapı: if + had + subject + past participle, would + have + past participle
- İlk cümle (if clause): If you had arrived earlier...
- İkinci cümle (main clause): ...you would have caught the bus.
- If I had known about the party, I would have attended.
- If they had practiced more, they would have won the competition.
- If she had saved her money, she would have bought a house.

## Olumsuz Yapı

- If cümlesinde olumsuzluk: If you had not forgotten your keys, you wouldn't have called me.
- Main cümlesinde olumsuzluk: If I had studied, I still would not have understood the material.
- Her iki cümle de olumsuz olabilir: If you hadn't lied to me, I wouldn't have left you.
- If they hadn't missed the train, they would not have been late for work.
- If he hadn't been sick, he wouldn't have missed the interview.

## Soru Yapısı

- Yapı: Would + subject + have + past participle + if + had + subject + past participle
- Would you have helped him if he had asked?
- Would she have gotten the job if she had prepared better for the interview?
- Would they have survived if rescue had come earlier?
- Evet-hayır sorular: Would I have made the same mistake if I had been more careful?
- Wh- sorular: What would have happened if you had said no? / Where would they have gone if they had more money?

## Zaman Belirteçleri

- Geçmiş zamana referans: If I had done that yesterday, everything would have changed.
- Otherwise kullanımı: I didn't go to the party; otherwise, I would have met him. (would have + past participle)
- If only yapısı: If only I had known! If only you had listened to me!
- Had I known, I would have told you. (formal, inverted form)
- Without ifadesi: Without your help, I would have failed.

## Yaygın Hatalar

- Yanlış: If I would have known, I would have helped. Doğru: If I had known, I would have helped.
- Yanlış: If she had gone, she would be happy now. (Bu karışık koşul yapısıdır.) Doğru: If she had gone, she would have been happy.
- Yanlış: If I had studied, I passed the exam. Doğru: If I had studied, I would have passed the exam.
- Yanlış: If you didn't come, I would have left. Doğru: If you hadn't come, I would have left.
- Yanlış: Would you have come if I ask you? Doğru: Would you have come if I had asked you?
- Main cümlesinde had kullanmak: If he studied, he had passed. (Yanlış) Should be: If he had studied, he would have passed.
- Zaman karışıklığı: If I had known last week, I would help you now. (Yanlış) Doğru: If I had known last week, I would have helped you then. VEYA If I knew now, I would help you.
