Koşul cümlelerinin ilki olan First Conditional, gelecekte gerçekleşmesi muhtemel veya mümkün olan durumları anlatmak için kullanılır. İki cümlenin birleşmesiyle oluşur: biri şartı (if clause), diğeri sonucu (main clause) belirtir.

## Ne Zaman Kullanılır

- Gelecekte gerçekleşmesi muhtemel durumlar için: If it rains tomorrow, I will stay at home.
- Belirli koşullar altında alınacak kararlar için: If you study hard, you will pass the exam.
- Neden-sonuç ilişkisi gösteren cümleler için: If you invite me, I will come to your party.
- Genellikle bu durumlar kontrol edilebilir ve makuldür; çok soyut veya hayal ürünü değildir.

## Yapısı: Olumlu Cümleler

- Temel şekil: If + simple present, will + base verb
- If clause (şart cümlesi) simple present tense kullanır: If you call me, I will answer.
- Main clause (ana cümle) will + fiil (future simple) kullanır: If she arrives early, we will go to the cinema.
- If cümlesi başta veya sonda gelebilir: I will buy a new car if I get a job. / If I get a job, I will buy a new car.

## Yapısı: Olumsuz ve Soru

- Olumsuz: If you don't eat breakfast, you will feel hungry.
- Olumsuz if clause: If it doesn't rain, we will play outside.
- Olumsuz main clause: If you wake up late, you will not finish your work on time.
- Soru cümlesi: Will you call me if you arrive home late? / If you have time, will you help me with this?
- Sorular genellikle main clause içinde will ile başlar: Will you forgive me if I apologize? / If you don't like it, will you tell me?

## Zaman İfadeleri

- Tomorrow, next week, next month: If I see you tomorrow, I will tell you the news.
- Later, soon, in a few days: If you call soon, I will answer my phone.
- When (eğer "when" kesin bir future anlamında kullanılıyorsa, first conditional ile kullanılır): When you arrive, I will prepare dinner. (Burada "when" = "if")
- If clause'da "will" değil simple present kullanılır: If it will rain (YANLIŞ) → If it rains (DOĞRU)

## Sık Yapılan Hatalar

- If clause'da will kullanmak: If you will study, you will pass (YANLIŞ) → If you study, you will pass (DOĞRU)
- Zaman uyumuna dikkat etmemek: If she goes to the party, she was happy (YANLIŞ) → If she goes to the party, she will be happy (DOĞRU)
- If ve when'i karıştırmak: When you come, I will be waiting for you (doğru, kesin gelecek). But: If you come, I will be waiting for you (doğru, tercih meselesi).
- Virgül kural: If clause başında ise virgül gerekir; sonda ise genellikle virgül gerekmez: If it rains, we will cancel the game. / We will cancel the game if it rains.
- Main clause'da başka tense kullanmak: If you heat ice, it will melt (DOĞRU); If you heat ice, it melts (bu ikinci conditional gibi görünür ancak general truth'dür).

## Kontrastlar: Diğer Koşul Cümleleri

- Second Conditional ile karıştırmamak: First conditional gerçekçi ve mümkün durumlar için; If I win the lottery, I will travel around the world (mümkün) vs. If I were a bird, I would fly (imkansız/hayal ürünü).
- Unless kullanımı: Unless you study, you will fail (= If you don't study, you will fail).
- Başka future forms: I might go / I could go / I'm going to go de ana cümlede kullanılabilir: If you come early, I might prepare lunch. / If it snows, we could have a snowball fight.
