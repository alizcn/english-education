Second conditional, gerçekleşmesi düşük ihtimalli veya imkansız durumları anlatmak için kullanılır. Bu yapı, hayali veya teorik koşullar hakkında konuşurken sık kullanılır.

## Ne Zaman Kullanılır

- Başında bir koşul (if cümlesi) olmak üzere iki cümleden oluşur.
- Koşul gerçekleşmesi pek olası olmayan bir durumu, rüya, hayal veya imkansız bir durumu anlatır.
- If it rained tomorrow, I would stay home.
- If I were you, I would accept the job.
- If she had a car, she would drive to work.

## Yapısı: Olumlu Cümleler

- Yapı: If + past tense, would + base verb
- If I won the lottery, I would travel around the world.
- If you studied hard, you would pass the exam.
- If he called me, I would answer immediately.
- If they arrived on time, we would start the meeting.

## Yapısı: Olumsuz Cümleler

- Yapı: If + past tense (negative), would + base verb
- If I didn't work tomorrow, I would go to the beach.
- If she didn't like him, she wouldn't spend time with him.
- If they didn't live so far away, they would visit us more often.
- If you weren't so lazy, you would finish your homework.

## Yapısı: Sorular

- Yapı: Would + subject + base verb + if + past tense?
- Would you travel if you had enough money?
- Would she be happy if he proposed to her?
- Would they come if we invited them?
- Cevaplar: Yes, I would. / No, I wouldn't.

## Were Kullanımı

- I was yerine I were, he was yerine he were kullanılır second conditional'da resmi yazı ve konuşmada.
- If I were rich, I would buy a mansion.
- If you were in my situation, what would you do?
- If she were older, she would be allowed to work.
- If he were a better student, he would apply to Harvard.

## Zaman İfadeleri

- Second conditional future veya genel durumları anlatmak için kullanılır.
- Tipik zaman ifadeleri: tomorrow, if it were possible, in that case
- If the weather were nicer tomorrow, we would go hiking.
- If you gave me a chance, I would prove myself.
- If they offered me more money, I would consider changing jobs.

## Öğrenenlerin Sık Yaptığı Hatalar

- Hata: If I would win the lottery, I would travel. Doğru: If I won the lottery, I would travel.
- Hata: If she was a singer, she would be famous. Doğru: If she were a singer, she would be famous.
- Hata: If they had money, they buy a car. Doğru: If they had money, they would buy a car.
- Hata: If it rain tomorrow, I would stay home. Doğru: If it rained tomorrow, I would stay home.
- Hata: If he come to the party, it would be fun. Doğru: If he came to the party, it would be fun.
