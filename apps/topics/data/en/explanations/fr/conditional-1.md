Le First Conditional (ou première conditionnelle) est une structure grammaticale essentielle en anglais qui permet d'exprimer des situations futures qui dépendent d'une condition. C'est probablement la structure conditionnelle la plus utilisée en anglais.

## Quand utiliser le First Conditional

- On utilise le First Conditional pour parler d'une situation future qui est possible et réaliste.
- La condition dans la clause "if" est considérée comme probable ou simplement possible.
- Cette structure exprime les conséquences futures d'une action ou situation présente.

Exemples:
- If you study hard, you will pass the exam.
- If it rains tomorrow, we will cancel the picnic.
- If she calls me, I will answer immediately.

## Structure positive du First Conditional

Le modèle principal est: if + present simple, will + infinitif sans "to".

La clause "if" peut venir en premier ou en deuxième position. Si elle est en premier, on utilise une virgule avant la clause principale.

Exemples avec "if" en premier:
- If you eat too much, you will feel sick.
- If he works late, he will miss dinner.
- If they arrive early, we will have time to prepare.

Exemples avec "if" en deuxième position:
- You will pass the test if you prepare well.
- She will be happy if you buy her flowers.
- We will go out if the weather is nice.

## Structure négative du First Conditional

Pour la forme négative, on utilise "will not" (ou "won't") dans la clause principale. On peut aussi ajouter "not" dans la clause "if".

Négation seulement dans la clause principale:
- If you come late, you will not get a seat.
- If it snows, we will not go outside.

Négation seulement dans la clause "if":
- If you don't study, you will fail.
- If she doesn't call, I will be worried.

Négation dans les deux clauses:
- If you don't try hard, you will not succeed.
- If he doesn't sleep, he will not be energetic.

## Questions et forme interrogative

Pour poser une question, on inverse l'ordre du sujet et de "will" dans la clause principale. La clause "if" garde son ordre normal.

Exemples:
- Will you go out if it is sunny?
- If you win the lottery, will you buy a house?
- Will she come to the party if you invite her?
- What will you do if you lose your phone?
- Where will you go if the weather is bad?

## Marqueurs temporels et expressions caractéristiques

Le First Conditional utilise toujours le present simple dans la clause "if", jamais le futur. Les marqueurs temporels courants sont: tomorrow, next week, this afternoon, as soon as, etc.

Exemples:
- If he arrives tomorrow, we will go to the cinema.
- If you see him next week, tell him to call me.
- If it rains this afternoon, we will stay inside.
- As soon as you finish, you will need to help me.

## Règles d'orthographe et de morphologie

Les verbes au present simple dans la clause "if" ne prennent pas de forme spéciale (sauf "to be" avec "is" et "are").

La base du verbe après "will" ne prend jamais de terminaison "-s" ni aucune autre flexion:
- If you come, I will help you. (pas "will helps")
- If they arrive, we will wait. (pas "will waits")

Les verbes irréguliers gardent leur forme irrégulière habituelle:
- If I go, you will see me.
- If she buys a car, she will drive to work.
- If he takes the train, he will arrive at six.

## Erreurs courantes des apprenants francophones

Erreur 1: Utiliser le futur dans la clause "if"
- Incorrect: If you will study, you will pass.
- Correct: If you study, you will pass.

Erreur 2: Oublier "will" dans la clause principale
- Incorrect: If you come, I go.
- Correct: If you come, I will go.

Erreur 3: Ajouter un "s" au verbe après "will"
- Incorrect: If he comes, he will helps me.
- Correct: If he comes, he will help me.

Erreur 4: Confondre "if" avec "whether"
- "If" introduit une condition réelle.
- "Whether" introduit un choix ou une question indirecte.
- Exemple correct: If you study, you will succeed.
- Exemple avec whether: I don't know whether to go or stay.

Erreur 5: Utiliser "would" au lieu de "will"
- Incorrect: If you study, you would pass.
- Correct: If you study, you will pass.
- Note: "Would" s'utilise avec le Second Conditional, pas le First.
