Le passif allemand est une construction grammaticale qui change la perspective d'une phrase. Au lieu de mettre en avant celui qui fait l'action, on met en avant celui qui la subit. Cette transformation est très utile pour décrire des processus, des événements ou quand l'auteur de l'action est inconnu ou sans importance.

## Quand et pourquoi utiliser le passif

- Le passif est utilisé quand l'action est plus importante que l'agent. Der Brief wird geschrieben. (La lettre est écrite.)
- Il est fréquent dans les textes scientifiques, journalistiques et formels. Das Experiment wurde durchgeführt. (L'expérience a été réalisée.)
- Quand l'auteur est inconnu ou volontairement omis. Die Tür wurde geöffnet. (La porte a été ouverte.)
- Avec les expressions temporelles courantes : gestern (hier), heute (aujourd'hui), morgen (demain), im Jahr 2020. Das Projekt wird morgen beendet. (Le projet sera terminé demain.)

## La formation du passif au présent et au passé

- Le passif se forme avec l'auxiliaire werden + le participe passé du verbe principal.
- Présent : werden (au présent) + participe passé. Das Buch wird gelesen. (Le livre est lu.)
- Prétérit : wurde + participe passé. Das Buch wurde gelesen. (Le livre a été lu.)
- Parfait : sein (au présent) + participe passé + worden. Das Buch ist gelesen worden. (Le livre a été lu.)
- Plus-que-parfait : sein (au prétérit) + participe passé + worden. Das Buch war gelesen worden. (Le livre avait été lu.)
- Remarque importante : le participe passé de werden est worden, pas geworben.

## Le passif à la forme négative

- Ajoutez nicht avant le participe passé. Der Brief wird nicht geschrieben. (La lettre n'est pas écrite.)
- Au prétérit : wurde nicht + participe passé. Der Brief wurde nicht geschrieben. (La lettre n'a pas été écrite.)
- Vous pouvez aussi utiliser kein ou keine pour nier le sujet ou l'objet. Es wurden keine Fehler gemacht. (Aucune erreur n'a été commise.)

## Les questions au passif

- L'ordre des mots pour les questions : verbe auxiliaire + sujet + compléments + participe passé.
- Wird das Haus renoviert? (La maison est-elle rénovée?)
- Wurde das Projekt abgeschlossen? (Le projet a-t-il été achevé?)
- Avec un mot interrogatif en première position : Wann wird die Brücke gebaut? (Quand le pont sera-t-il construit?)
- Avec préposition : Womit wird der Tisch gereinigt? (Avec quoi la table est-elle nettoyée?)

## L'agent, les prépositions von et durch, et l'état versus le processus

- Pour mentionner celui qui fait l'action, utilisez von + datif avec les personnes. Das Lied wird von Maria gesungen. (La chanson est chantée par Marie.)
- Utilisez durch + accusatif avec les instruments ou les causes. Das Fenster wurde durch einen Ball zerstört. (La fenêtre a été détruite par une balle.) Das Projekt wurde durch Zeitmangel verzögert. (Le projet a été retardé par manque de temps.)
- Le passif de processus (avec werden) décrit une action en cours. Das Fenster wird geöffnet. (On ouvre la fenêtre.)
- Le passif d'état (avec sein) décrit un état résultant. Das Fenster ist offen. (La fenêtre est ouverte.)

## Les morphologies et règles d'orthographe

- Les participes passés réguliers prennent le préfixe ge- et le suffixe -t : machen → gemacht. Das Fenster wird gemacht. (La fenêtre est faite.)
- Les participes passés irréguliers varient : schreiben → geschrieben, singen → gesungen, nehmen → genommen.
- Les verbes avec préfixe séparable forment leur participe avec ge- entre le préfixe et la racine : aufmachen → aufgemacht. Der Laden wird aufgemacht. (Le magasin est ouvert.)
- Les verbes avec préfixe inséparable (be-, ent-, er-, ver-, zer-) ne prennent pas de ge- : besuchen → besucht. Die Stadt wird besucht. (La ville est visitée.)
- Les verbes en -ieren prennent -t sans ge- : organisieren → organisiert. Die Feier wird organisiert. (La fête est organisée.)

## Les erreurs courantes

- Erreur 1 : mauvais placement du participe passé. Correct : Das Buch wird gelesen. Incorrect : Das Buch gelesen wird.
- Erreur 2 : confondre passif d'état et passif de processus. Das Fenster ist offen décrit un état, pas une action. Pour l'action, utilisez Das Fenster wird geöffnet.
- Erreur 3 : confondre von et durch. Incorrect : Das Fenster wird durch der Mann geöffnet. Correct : Das Fenster wird von dem Mann geöffnet.
- Erreur 4 : oublier que werden au passif prend la forme worden. Incorrect : Das Buch ist gelesen geworben. Correct : Das Buch ist gelesen worden.
- Erreur 5 : mal placer nicht dans les questions négatives. Correct : Wird der Brief nicht geschrieben? Incorrect : Wird nicht der Brief geschrieben?
- Erreur 6 : appliquer des règles de participes actifs aux participes passifs. Les règles de formation du participe (ge-, préfixes) s'appliquent au verbe principal, pas à werden.
